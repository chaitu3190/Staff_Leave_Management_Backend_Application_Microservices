Staff Leave Management System - Microservices Backend Application

About the Project

This is a Staff Leave Management System that I am developing using Java and Spring Boot. The main purpose of this project is to manage staff details and leave related activities.

I have divided the backend into three microservices to keep the different responsibilities separate. I am building this project as a way to improve my practical knowledge of Spring Boot, database connectivity, and microservices.



Microservices

1. Staff_Service:
This service handles staff related operations.

2. LeaveService:
This service is for leave related operations.

3. AdminService:
This service is for administrative operations.


Technologies Used

- Java
- Spring Boot
- Maven
- MySQL
- REST APIs

Project Structure

This project is maintained in a single GitHub repository. It contains three Spring Boot service projects:

- Staff_Service - The source code is located at the repository root.
- LeaveService - The source code is in the "LeaveService/" folder.
- AdminService - The source code is in the "AdminService/" folder.

Each service has its own source code and Maven configuration.

How to Run the Project

1. Install Java and MySQL.
2. Open each service in Spring Tool Suite (STS).
3. Configure the database connection and required environment variables.
4. Run each service as a Spring Boot application.
5. Test the available endpoints using a suitable API testing tool.

What I Learned

While working on this project, I am learning how to create Spring Boot applications, connect them to a database, organize backend code into separate services, and work with GitHub to manage my project.
